# METAL KAP 2 PHONE

Tracker chip-punk pour Android, qui marche hors ligne. Ouvre la page dans Chrome, puis menu ⋮ → « Ajouter à l'écran d'accueil ».

Version téléphone du plugin METAL KAP 2 : même moteur (compilé en WebAssembly), mêmes morceaux. Les morceaux s'exportent en `.mk2.json` et s'importent dans le plugin par le Wi-Fi (page SAVE / LOAD → Téléphone).
