SOURIS : clic = choisir la case · re-clic sur NOTE ou CMD = menu · molette = monter/descendre (Maj = octave) · clic droit = effacer · clic sur KCK/SNR/HAT = on/off.
CLAVIER : Z S X D C V… / Q 2 W 3 E… = notes · 1 = OFF · Entrée = dernière note · Suppr = effacer · flèches · hexa dans VOL / VAL · Tab = piste suivante · Espace = play · commandes au clavier : A arp · S slide · R retrig · K kill · V vib · O oct · H hop · L vol · D delay · C chance · P pitch. Si Ableton vole les touches : clique d'abord dans le plugin, ou utilise REC MIDI avec ton clavier MIDI. 8 pistes de notes (T1-4 / T5-8) + drums · clic sur le nom d'une piste = mute. Une nouvelle note coupe la précédente sur sa piste.
SÉLECTION : Maj+flèches, Maj+clic ou glisser à la souris · Ctrl/Cmd C X V copier / couper / coller (seulement les colonnes choisies : que les notes, que les CMD…, ça se recale sur la piste du curseur) · Ctrl/Cmd Maj V coller en mix (les vides n'effacent rien) · Ctrl/Cmd A colonne → piste → tout · + − transpose la sélection · Ctrl/Cmd Z annuler

Chain

チェーン

L'ordre des phrases quand le MODE est sur CHAIN. Clic = choisir · molette = changer le numéro · clic droit = vider · double-clic = ouvrir la phrase.

Synth

シンセ

Glisse un fichier audio depuis le navigateur d'Ableton ou le Finder sur cette page (ou sur le nom d'une piste dans le tracker) : il devient le sample de l'instrument. 8 instruments (00 à 07). 8 pistes : bouton T1-4 / T5-8 au-dessus du tracker. La colonne IN du tracker choisit lequel joue. Dans le tracker : le petit bouton ∿ à côté du nom d'une piste, ou un double-clic sur sa case IN, ouvre son synthé. Ton clavier MIDI joue l'instrument de la piste où est le curseur.

Drums

ドラム

5 pistes de drums : KICK, SNARE, HAT, OPEN HAT (coupé par le HAT), PERC. Chaque piste prend une machine de METAL KAP 1 ou le son CLASSIQUE, et peut passer par Paula.

RÉGLAGES DU SON CLASSIQUE

Roll

ロール

Les notes de la phrase en lignes de couleur (couleur = registre de la piste), et par-dessus ce qui sonne vraiment en direct : arpèges, glissés, vibrato, pitch et escalier de la manette. La trace du tour d'avant reste en fantôme.
MPE : choisis une piste et dessine sur ses notes à la souris : la note suit ta courbe (glissés, vibratos, chutes…). Clic droit ou Maj = gomme. AIMANT = la courbe saute de note en note. Une note avec une courbe a un « ~ » dans le tracker.

Morceaux

セーブ

Sauve tout le morceau : les 16 phrases, la chaîne, les 8 instruments, les drums, la gamme, le swing et les réglages des twists. Les fichiers vont dans Musique / METAL KAP 2 / Songs, tu peux les copier ou les partager.

Téléphone

電話

METAL KAP 2 sur ton téléphone Android, même son, même tracker. Le Mac et le téléphone sur le même Wi-Fi : active, scanne le QR code avec l'appareil photo du téléphone (ou tape l'adresse dans Chrome). Ce que tu sauves sur le téléphone arrive direct ici, dans les morceaux. Le téléphone garde aussi ta session tout seul. Au premier coup, le Mac peut demander d'autoriser les connexions entrantes pour Ableton : accepte.

Effets

エフェクト
A / B : maintiens = phrase B, tu lâches = retour sur A

Delay et reverb en envoi : chaque piste choisit combien elle envoie. Le delay suit le tempo. Astuce : mets un slot de la manette sur DELAY THROW pour balancer les pistes touchées dans le delay en tenant le bouton (le dub style).

Manette

パッド

Branche ta manette Xbox (USB ou Bluetooth) : le plugin la lit directement, même fenêtre fermée. Choisis ce que fait chaque bouton. Les twists déforment la musique en direct, ils n'effacent rien.
AUTOMATION : tous les twists sont des paramètres du plugin (Twist Stutter, Twist Pitch, Twist Filter, Twist A/B/X/Y, Twist Reverse, Twist Staircase…). Arme l'enregistrement d'automation dans Ableton, joue à la manette ou avec les boutons de l'écran : Ableton enregistre tes gestes et les rejoue. Tu peux les retoucher dans Ableton comme n'importe quelle automation.
